# Security reporting

Please **do not open a public issue containing credentials, hostnames, personal reports, serial numbers, network information, exploit data, or other sensitive diagnostics**.

Use GitHub's **Private vulnerability reporting** feature for this repository **if the repository owner has enabled it** (repository → Security → Advisories → Report a vulnerability). If unavailable, request a private communication channel from the maintainer without posting the sensitive details publicly. No dedicated security email address or response SLA is claimed.

This project is an educational, read-only diagnostic aid, not a security control. Do not use it to infer that a computer is safe, compliant, or free from malware. Respect device authorization and standard-user execution.
